# Recovery and spending evidence

The saved production run used zero automatic retries. Its real unknown-charge failure remains failed, with null usage/charge and the documented separate $0.05 hold. The stopped enrich role and paused scheduler remain in force. The actual interruption/resume pilot is [resume.cast](../pilot100_optimized/resume.cast); no completed IDs were paid to relabel in its warm repeat.

The revised dispatcher allows at most one retry for a schema/ID-invalid response or HTTP 429/500/502/503/504 only when the actual provider response reports valid usage. Backoff is 0.25×2^attempt plus jitter up to 0.25 seconds. Each attempted call is separately persisted and the shared cap/rate reservation is checked before retry. Timeout/unknown usage stops dispatch; it is never assumed free. Two-worker admission requires both active calls to belong to the same owned run lock and validates held plus active reservations; foreign/unowned calls block admission.

These paths were demonstrated with isolated transport fixtures, not a claimed live transient-error recovery: known-usage malformed response retries once and accounts for both attempts; known-usage HTTP 503 retries with measured fixture backoff; a second malformed result stops without a third call; unknown timeout is retained and never retried; foreign concurrency and over-cap reservations block dispatch. [Actual offline test output](offline_tests.txt) records 98 passing tests. [Live worker comparison](../worker_comparison/report.md) separately demonstrates real overlapping requests without failures or retries.
