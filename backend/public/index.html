Scope, methods and limitations

Jev classifies topic and intent, and scores severity for complaints or cancellations; code assigns severity 1 to no-problem intents. A separate blind Jev task verifies a sample. Local VADER uses a dictionary and rules to score sentiment. Local Qwen drafts issue names and recommendations from selected metrics and review quotes. Code computes counts and rankings; editorial review checks the final wording. Sentiment does not enter the priority calculation. Identical texts may reuse a compatible saved classification while preserving each original review ID and fingerprint.

The classification version combines the model, prompt version and a fingerprint of non-secret settings. It contains no credentials.

This fingerprint identifies the 244,582-review analysis CSV, rather than the original full dataset. It checks file consistency; it is not a key or a file-access link.
